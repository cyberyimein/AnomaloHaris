# Buddy Presence

Use this skill when the remote LLM needs Buddy to **express state** rather than execute raw protocol
commands.

Prefer these high-level tools for:

- changing Buddy visual state (`idle`, `thinking`, `speaking`, `coding`, `done`, `error`)
- updating short on-screen status text
- giving a quick LED cue
- turning Buddy's head toward a target

Keep text short because Buddy screen space is limited. Do not use this skill for approval, raw
transport debugging, reboot/shutdown, or display capture.
