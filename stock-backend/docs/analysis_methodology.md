# KabuLens 分析方法与证据边界

KabuLens 当前是开盘前注意力分配工具，不是收益率预测模型。它应该回答三个不同问题：

1. 今天哪些标的值得花时间看？
2. 已完成日线给出的方向背景是什么？
3. 哪个价格触发或失效条件会让情景更可信？

`attention_score` 只回答第一个问题。方向与把握度分别位于 `stocks[].signal.direction` 和
`stocks[].signal.confidence`，不能把高注意力分直接翻译成买入。

## 指标价值审计

| 数据/指标 | 有效用途 | 不能证明什么 | 当前处理 |
| --- | --- | --- | --- |
| EMA 趋势与斜率 | 中期方向背景、顺势/逆势分类 | 精确入场点、底部 | 保留，并只使用已完成日线 |
| 相对强度（个股 vs 分组基准/SPY） | 判断个股是否得到所属方向和大盘资金配合 | 单日必然继续上涨 | 按组使用 SOXX、QQQ 或 IGV，并要求 5 日与 20 日双周期确认 |
| 当前涨跌幅 / ATR | 判断今天的移动是否异常、是否值得查催化 | 缺口会延续还是回补 | 作为注意力分的最大组成；达到 1 ATR 或绝对 5% 时至少进入观察，不参与方向判断 |
| 当前时段量 / 20 日 ADV | 判断参与度 | 未做同一时刻基准前，不能精确称为异常量 | 保留并标记 `time_of_day_adjusted=false` |
| 昨高低、周高低、摆动点 | 触发位和失效位 | 支撑必然守住 | 改为距离当前价最近的已完成日线关键位 |
| RSI | 动量是否拉伸 | 超卖等于见底、超买等于见顶 | 只作 setup 修饰条件，不单独发信号 |
| 布林 %B | 当前价处于历史波动带的位置 | 触轨后必然反转 | 与 EMA 方向和 ADX 结合：强趋势可贴轨，弱趋势才观察均值回归 |
| 布林宽度分位 | 波动相对自身历史是否收窄 | 突破方向 | 同时检查绝对 ATR/带宽，避免把高波动票叫作低波动挤压 |
| ADX 14 | 区分趋势推进与弱趋势震荡 | 趋势方向、买卖点 | 只定义趋势强弱；方向仍由 EMA 结构判断 |
| 四个观察组广度 | 判断科技内部是普涨、普跌还是轮动，并给个股同伴确认 | 全市场广度、独立预测信号 | 当前股票从同伴计算中排除；只作确认，不进入大盘风险分 |
| ATM 跨式价格 | 最近到期的非方向性隐含波动范围 | 上涨或下跌概率 | 保留，并增加买卖价差质量 |
| ATM IV / 20 日实波 | 期权相对近期实际波动是否昂贵 | 股价方向 | 保留，深度虚值合约不再进入平均 IV |
| Put/Call、成交量/OI | 活跃度和保护需求的背景 | 买卖方向、开仓/平仓意图 | 不计方向分，不计注意力分，默认折叠 |
| Gamma 与 OI | 可标记短期期权敏感价位 | 仅凭美国期权 OI 不能判断 dealer 正/负 gamma | 删除“负 gamma”和“gamma 挤压候选”结论 |
| UUP/TLT/GLD/USO | 条件式宏观背景 | 固定的一对一 risk-on/risk-off 映射 | 完全移出大盘风险分，仅显示背景 |
| VIXY | VIX 期货压力的短期替代 | 现货 VIX 水平或长期趋势 | 只使用短期变化，不使用 EMA 长趋势 |

### 时段涨跌口径

盘前、隔夜和盘后涨跌必须相对最近一次常规收盘，而不能相对 OpenD 的原始
`prev_close_price`。在开盘前，OpenD 的 `last_price` 通常是最近常规收盘，
`prev_close_price` 可能是再前一个交易日收盘；直接用后者会把昨日常规涨跌错误地并入盘前。

OpenD 的 `pre_change_rate`、`overnight_change_rate` 和 `after_change_rate` 也可能采用
累计口径，因此 KabuLens 不使用它们打分。扩展时段统一用时段价格相对 `last_price`
计算，并在 `session_quote.reference_price`、`reference_type` 和 `change_source` 中公开
口径。供应商原始值只保留在 `raw_opend_change_pct`，同时明确
`raw_opend_change_used=false`。

## 大盘模型 v2

大盘 `risk_score` 只由三块输入组成：

- 指数：SPY、QQQ、IWM，权重 50%。
- 波动率：VIXY 的短期变化，权重 30%。
- 科技广度与风格：SOXX（SOX 的可交易代理）和 IGV（软件），合计权重 20%。两者同向时
  用于确认科技广度；明显反向时识别为半导体/软件内部轮动，不把平均值解释成“混合领导力”，
  且该块从大盘方向合成的分子和分母同时移除，避免无方向信息稀释指数与波动率信号。
  数据完整度仍按已成功获取计算。轮动关系按当前数据识别，不假设永久负相关。

指数和科技 ETF 的单标的内部方向分范围为 `-100..+100`：当前时段相对 ATR 最多
`±45`，近 5 日相对 ATR 最多 `±25`，EMA 结构与斜率趋势最多 `±30`。波动率块只使用
VIXY 当前时段与近 5 日变化，合计压力分取反，因此正数表示压力缓和。`±20` 内视为混合，
超过 `+20` 视为偏强，低于 `-20` 视为偏弱。所有分数都没有自然单位，不是概率或预期收益。

四个自选观察组只形成科技内部广度与轮动确认，不与 SOXX/IGV 重复进入风险分。美元、长债、
黄金和原油只进入情景解释。`data_coverage` 表示数据是否齐全；`signal_confidence` 表示信号
强度和三块输入的一致程度，但仍不是胜率。

## 注意力模型 v2.2

`attention_score` 的 100 分由五个用途不同的部分组成：

| 组成 | 上限 | 作用 |
| --- | ---: | --- |
| 当前移动 | 45 | 缺口相对 ATR 的显著性；达到 1 ATR 或绝对 5% 时单项直接给 45 分，确保至少检查催化 |
| 可执行 setup | 25 | 支撑、突破、趋势回调及条件化布林行为 |
| 时段参与度 | 10 | 当前时段量/20 日 ADV；未有同一时刻历史基线前主动降权 |
| 期权风险 | 10 | 隐含范围、IV/实波和短期期权敏感位，仅提示幅度 |
| 上下文对齐 | 10 | 相对强度、同组确认和可用的大盘方向 |

大幅移动只保证“值得调查”，不改变 `signal.direction`。例如一只股票大幅高开但日线趋势和
相对强度仍弱，可以同时是 `observe` 和 `bearish`，含义是“先查原因并等待触发”，不是追涨。

## 自选分组

| 分组 | 股票 | 相对强度基准 | 用途 |
| --- | --- | --- | --- |
| 半导体 / 存储 | INTC、AMD、MU、SNDK、SKHY | SOXX | 观察 SOX 代理与组内广度是否共同确认 |
| 光模块 / 网络 | LITE、COHR、MRVL、NOK | QQQ | 观察 AI 网络链的组内扩散，不把它误算成完整半导体指数 |
| 算力 / 云基础设施 | NVDA、NBIS、ORCL | QQQ | 观察算力到云资本开支方向的同步性 |
| 软件 | MSFT、NOW、PLTR | IGV | 观察软件领导力与组内个股是否一致 |

`SKHY` 在正式常规交易日前以 `scheduled` 出现在 `unavailable_symbols`，不会被当成抓取失败。

## 仍然缺少的关键数据

按价值优先级排序：

| 优先级 | 数据 | 价值 |
| --- | --- | --- |
| P0 | 为已自动存档的 OpenD 扫描补充未来 1 日/5 日结果 | 只有这项能检验规则是否真的有预测价值，并校准阈值 |
| P0 | 财报、公司事件、重大新闻及其时间 | 区分技术性移动与已知催化，解释 IV 和缺口 |
| P0 | 同一盘前时刻的历史累计量 | 把当前量转换成真正可比的盘前相对量 |
| P1 | 现货 VIX、VIX9D、VIX3M 或 VIX 期货曲线 | 取代 VIXY 的结构性偏差，识别短端压力和期限倒挂 |
| P1 | 市场广度：涨跌家数、站上 20/50 日线比例 | 判断指数上涨是否由少数权重股驱动 |
| P1 | SOX 原始指数或更完整的半导体成分广度 | 校验 SOXX 代理是否遗漏非 ETF 权重结构的变化 |
| P1 | 2 年/10 年美债收益率及变化 | 比 TLT 单一方向更直接地描述利率压力 |
| P1 | 期权报价时间、历史 IV 分位、逐日 OI 变化 | 提升跨式和 IV/HV 的可比性 |
| P2 | 开仓/平仓、主动买卖方向、做市商分类数据 | 才可能更严谨地研究 dealer gamma，而非从总 OI 猜测 |
| P2 | 空头仓位、可交易流通盘、借券费率 | 判断真正 squeeze 条件，而不是只看 Call 成交量 |

## 验证标准

在累积足够历史扫描前，所有阈值都应视为启发式。后续回测至少分别统计：

- 注意力命中率：高分标的是否真的出现了大于某个 ATR 的后续波动。
- 方向命中率：只有触发条件实际发生后，才评价 bullish/bearish 情景。
- 支撑/压力有效率：首次测试、收盘确认和次日延续要分开。
- 概率校准：`low/moderate/high` 三档是否对应递增的样本成功率。
- 基准比较：规则必须优于“全部观察”“只按缺口排序”等简单基线。

在这些结果出现前，前端应明确显示 `methodology.status = heuristic_not_backtested`。
