# Buddy Approval

Use this skill when the remote LLM needs a **human-in-the-loop approval** through Buddy.

This skill is for:

- showing an approval prompt on Buddy
- waiting for the touch response
- reading the result as approve or deny

Buddy only captures user intent. Approval policy and whether an action is actually executed must
remain on the Anomalo side.
